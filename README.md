# Python Contact Manager

A simple command-line contact manager built with Python and JSON.

## Features

- Add contacts
- Show all contacts
- Search contacts by name
- Delete contacts
- Prevent duplicate names
- Save and load contacts using JSON

## Technologies

- Python
- JSON

## How to Run

```bash
python contact_manager.py
